# VR-WhackAMole

VR 두더지잡기 미니게임 (Meta Quest, Quest Link 기반)

## 개발 환경
- Unity 6000.3.6f1
- XR Interaction Toolkit + OpenXR
- 실행 방식: Quest Link (PC 연결, 별도 APK 빌드 없음)

## 조작법
- 트리거(검지 버튼)를 누르고 있는 동안에만 손에 망치가 나타남
- 망치로 두더지를 내리쳐서 타격 (트리거를 떼면 망치가 사라져 오작동 방지)

## 플레이 방법
1. Start 버튼을 망치로 쳐서 게임 시작
2. 카운트다운(3, 2, 1, GO!) 후 제한시간 동안 두더지 타격
3. 시간이 지날수록 스폰 속도가 빨라지며 난이도 상승
4. 제한시간 종료 시 최종 점수 표시
5. Restart 버튼을 망치로 쳐서 재시작
